El programa fue elaborado en c++ con wxWidgets, por lo cual, a la hora de intentar correr el ejecutable se deberán instalar algunas dependencias como wxmswXXu_core.dll y wxbaseXXu.dll, el paquete "Microsoft Visual C++ Redistributable", ya que se realizó en Visual Studio, y libgcc_s_dw2-1.dll, libstdc++6.dll, o similares. Se pueden descargar desde sitios oficiales o SourceForge. Una vez instalados los dll, se pueden colocar en la misma carpeta donde esta el archivo. 
Ejemplo, si están en descargas, los dll deben estar en descargas.  
 
**NOTA:** Es posible que Windows lo detecte como posible amenaza, pero es totalmente seguro y confiable. El motivo de esto es que no es “conocido” al no haber firmas digitales.
